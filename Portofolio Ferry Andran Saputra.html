Dalam Pengembangan Aktif

Voice Door • AI Voice Recognition

Minecraft Mod (Forge 1.20.1) & Layanan AI Verifikasi Suara

Sistem keamanan biometrik suara mutakhir di dalam game Minecraft. Pintu hanya dapat terbuka jika pemain mengucapkan frasa rahasia "hi google open the door" dan sistem AI memverifikasi bahwa profil suara tersebut 100% cocok dengan pemilik pintu yang sah.

Alur Kerja Sistem (Architecture Pipeline)
Suara Pemain (In-Game) ➔ Forge 1.20.1 + Simple Voice Chat ➔ FastAPI REST Server ➔ Verifikasi ECAPA-TDNN ➔ STT Whisper / Vosk ➔ Pintu Terbuka!
  • ✔
    Mod Minecraft: Dibangun dengan Java 17 dan Minecraft Forge 1.20.1. Mengintegrasikan Simple Voice Chat API untuk menangkap audio real-time baik pada server dedikasi maupun mode LAN/Singleplayer.
  • ✔
    Layanan AI Voice Backend: Layanan Python FastAPI berlatensi rendah yang diamankan dengan autentikasi token. Memanfaatkan model ECAPA-TDNN untuk Speaker Verification dan fleksibilitas transkripsi (Google STT, Vosk, atau faster-whisper).
  • ✔
    Rencana Pengembangan Lanjutan: Integrasi dashboard Streamlit untuk perekaman sampel (enrollment suara), pembuatan dataset mandiri, serta evaluasi metrik akurasi biometrik: EER, FAR, FRR, WER, dan latensi pemrosesan.
