Minecraft Mod (Forge 1.20.1) & Layanan AI Verifikasi Suara

Sistem keamanan biometrik suara di dalam game Minecraft. Pintu hanya dapat terbuka jika pemain mengucapkan frasa rahasia "hi google open the door" dan sistem AI memverifikasi bahwa profil suara tersebut cocok dengan pemilik pintu yang sah.

Alur Kerja Sistem
Suara Pemain → Forge 1.20.1 → FastAPI Server → ECAPA-TDNN → STT Whisper → Pintu Terbuka
  • ✓
    Mod Minecraft: Dibangun dengan Java 17 dan Minecraft Forge 1.20.1. Mengintegrasikan Simple Voice Chat API untuk menangkap audio real-time.
  • ✓
    Layanan AI Backend: Python FastAPI berlatensi rendah dengan autentikasi token. Model ECAPA-TDNN untuk Speaker Verification dan transkripsi (Google STT, Vosk, atau faster-whisper).
  • ✓
    Pengembangan Lanjutan: Dashboard Streamlit untuk enrollment suara, pembuatan dataset mandiri, serta evaluasi metrik: EER, FAR, FRR, WER, dan latensi.
